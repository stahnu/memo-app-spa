# メモアプリ

React と Vite を用いて作成したシンプルなメモアプリです。
メモの作成・編集・削除ができ、データは LocalStorage に保存されます。

## 機能

- メモ一覧表示
- メモ詳細表示
- メモ追加
- メモ編集
- メモ削除
- LocalStorage を利用したデータ永続化

## 仕様

- メモの1行目をタイトルとして一覧表示
- タイトルをクリックすると編集状態へ移行
- 「+」ボタンで新規メモを追加
- 更新ボタンで内容を保存
- 削除ボタンでメモを削除
- ブラウザをリロードしてもデータを保持

## 使用技術

- React
- JavaScript
- Vite
- LocalStorage

## 起動方法

```bash
npm install
npm run dev
```
